fruit_knight.config.apply_difficulty(cfg, name)[source]¶

Build the configuration of a difficulty level.

Parameters:

  • cfg (fruit_knight.config.schema.GameConfig) – base configuration (the values outside difficulties).

  • name (str) – key inside cfg.difficulties.

Returns:

validated copy with the level’s overrides applied.

Return type:

fruit_knight.config.schema.GameConfig

Raises:

ConfigError – when the level is unknown or its overrides are invalid.

fruit_knight.config.load_config(path=None)[source]¶

Load and validate settings.yaml.

Parameters:

path (str | pathlib.Path | None) – YAML file location; bundled config/settings.yaml when omitted.

Returns:

validated typed configuration.

Return type:

fruit_knight.config.schema.GameConfig

Raises:

ConfigError – when the file is malformed or inconsistent.

fruit_knight.config.validate(cfg)[source]¶

Check semantic constraints of a loaded configuration.

Parameters:

cfg (fruit_knight.config.schema.GameConfig) – configuration to verify.

Raises:

ConfigError – when a value is out of bounds.
